## 1. Executive Summary

Phase 5 successfully expands the frozen 10-entity NutriBite NER baseline into a unified **13-entity sequence labeling architecture**. Using **only the 156 clinician-accepted dynamic candidates** from Phase 4 (`ai-service-v2/datasets/validated_candidates.json`), a clean, leak-free dataset partition (`dynamic_v1`) was formulated without modifying any existing training, validation, test, or human-gold evaluation files.

A new 13-entity Structured Averaged Sequence Perceptron was trained from scratch over 8 epochs with BIO transition masking. Evaluation on the held-out test partition demonstrated:
1. **Overall Micro-F1 reached 93.35%**, an improvement of **+0.54%** over the 10-entity Schema v2 baseline (92.81%).
2. **Flagship `NUTRIENT` performance was strictly preserved and slightly improved**: **92.44% F1** (+0.36% over baseline 92.08%).
3. **`COOKING_METHOD` achieved state-of-the-art performance**: **93.33% F1** (95.45% Precision, 91.30% Recall, Support: 23).
4. **`DIET_PATTERN` achieved perfect test accuracy**: **100.00% F1** (100.00% Precision, 100.00% Recall, Support: 2).
5. **Zero catastrophic forgetting across original entities**: 9 of the 10 original entity classes maintained $\ge 100\%$ retention or positive F1 gains.

## 4. Model Training Configuration

The 13-entity model was trained using the repository's native structured perceptron architecture:
- **Algorithm:** Structured Fast Averaged Sequence Perceptron
- **Decoding Constraint:** Transition masked BIO decoder (prevents illegal $O \rightarrow I\text{-}X$ and $B\text{-}X \rightarrow I\text{-}Y$ jumps)
- **Features Extracted (7,193 active features):**
  - Unigram token forms: lowercase word, length, is_title, is_upper, is_digit, has_hyphen
  - Subword n-grams: prefix-2, prefix-3, suffix-2, suffix-3
  - Local context window: previous word ($w_{i-1}$), next word ($w_{i+1}$), bigrams ($w_{i-1}\_w_i$, $w_i\_w_{i+1}$)
  - Transition state: previous predicted tag ($y_{i-1}$)
- **Hyperparameters:** 8 epochs, random seed 42, full trajectory parameter averaging
- **Convergence:** Token error rate decreased monotonically from $5.22\%$ (epoch 1) to $0.28\%$ (epoch 8).
